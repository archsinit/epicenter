# Whispering for Intel Mac

A fork of [Whispering 7.10.0](https://github.com/EpicenterHQ/epicenter/tree/v7.10.0/apps/whispering).

We're adding persistent Dock behaviour, a floating waveform and processing indicator, optional mouse shortcuts, a separate Enter shortcut, and an explicit LLM cleanup toggle.

Intel macOS only. We may add other platforms if there are requests.

Work in progress. No installer is ready yet.
