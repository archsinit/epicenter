# Whispering for Intel Mac

A fork of [Whispering 7.10.0](https://github.com/EpicenterHQ/epicenter/tree/v7.10.0/apps/whispering).

This fork adds persistent Dock behaviour, a floating waveform and processing indicator, optional mouse shortcuts, a separate Enter shortcut, and an explicit LLM cleanup toggle.

Intel macOS only. We may add other platforms if there are requests.

Work in progress. The first Mac startup test found a launch crash; a fix is being tested. Please do not use the earlier CI builds.
